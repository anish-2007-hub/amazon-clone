# Amazon Clone (Front-End Practice Project)

A static front-end clone of the Amazon home page, built with **HTML** and **CSS** to practice layout and styling.

🔗 **Live Demo:** [https://anish-2007-hub.github.io/amazon-clone/](https://anish-2007-hub.github.io/amazon-clone/)

## About

This project recreates the look of the Amazon home page to practise building real-world page layouts with plain HTML and CSS. It is purely visual: buttons and links are placeholders and nothing is stored or submitted.

## Features

- Top navigation bar with logo, search bar, language selector, account and cart sections
- Secondary navigation menu (All, Today's Deals, Customer Service, Gift Cards, Sell)
- Large hero banner with promotional image
- Product category cards such as "Shop for your home", "Fashion trend you like", "Get your game on" and "Easy updates"
- Flexbox / grid based layout
- Hosted for free on GitHub Pages

## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/anish-2007-hub/amazon-clone.git
   ```
2. Go into the folder:
   ```bash
   cd amazon-clone
   ```
3. Open `index.html` in your browser (double-click it, or use the Live Server extension in VS Code).

## Deployment

Deployed with **GitHub Pages** from the `main` branch (root folder):

1. Go to **Settings → Pages**.
2. Under **Source**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then click **Save**.
4. The site goes live at `https://<your-username>.github.io/<repo-name>/`.
